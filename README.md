# SteelMC Mobile
An unofficial Android (and later iOS) app for SteelMC

<img width="2379" height="1291" alt="steelmc-mobile-banner" src="https://github.com/user-attachments/assets/f234ecbc-f7f7-4712-95c9-c6cf4d3a25ae" />

## Downloads
You can download the latest version in the [actions](https://github.com/EricApostal/steel-mobile/actions) tab. It currently builds for Android, macOS and Linux, although the desktop builds are not the primary development target. This may later transition into a general SteelMC GUI, since desktop support is not difficult, and already partially exists for the macOS client.
